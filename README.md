# NEXUS

NEXUS measures the rules that decide which parts of a nervous system switch on, given the
animal's state. Each rule is written as a datasheet with six fields: Trigger, Threshold, Timing,
Reach, Priority and Cost.

This branch (`phase1-v2`) builds the Phase 1 test bench: simulated circuits with planted
switches, used to check that NEXUS finds the switches that are there and refuses to invent ones
that are not. Work is in progress and no results are public yet.

The earlier Phase 1 study (a BETSE bioelectric surrogate, August to September 2026) is closed
and archived in [`archive/phase1-betse/`](archive/phase1-betse/). Start with its
[README](archive/phase1-betse/README.md), which says what that study did and did not establish.
